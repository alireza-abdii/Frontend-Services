# Image To Component Service

Converts uploaded icon images (`png/jpg/jpeg/webp/svg`) into reusable JSX or TSX component files.

## Local

```bash
cd /home/daraei/Documents/Projects/services/image_to_component/app
./start.sh
```

- Frontend: `http://localhost:5175`
- API + standalone app shell: `http://localhost:8100`

## Docker

```bash
docker compose up --build -d
```
